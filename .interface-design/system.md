# ExamMind Midnight Studio

The canonical interface decisions live in `design-system/exammind/MASTER.md`.

- Direction: dark academic workspace with near-black studio surfaces, oversized editorial type, and disciplined electric lime.
- Depth: lifted panels and occasional product-window perspective; rules and spacing do most of the work.
- Spacing: 4px base, 8/12/16/20px component rhythm, 24px between panels, 48px+ between major regions.
- Hierarchy: next study action first, archive evidence second, course/readiness detail next.
- Reusable patterns: floating public nav, HTML product preview, lime material band, asymmetric capability bento, segmented metric strip, 76px course rows, inline-SVG charts, and explicit recovery states.
- Typography: Instrument Serif for editorial emphasis, DM Sans Variable for UI, JetBrains Mono Variable for codes and data.
- Accent semantics: lime for brand/action, teal for verified source evidence, amber for attention, coral for errors.
- Scope: this pass changes the public landing, authenticated dashboard and shared shell/tokens only; other routes keep their existing structure.
