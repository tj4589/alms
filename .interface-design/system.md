# ExamMind Workbench System

The canonical interface decisions live in `design-system/exammind/MASTER.md`.

- Direction: focused academic workbench with a charcoal desk, amber highlighter, paper-white type, and restrained verified teal.
- Depth: quiet surface shifts and rules; shadows only for overlays.
- Spacing: 4px base, compact controls, 32px to 48px between major groups.
- Hierarchy: study decision first, grounded search second, course/source evidence next.
- Reusable patterns: 42px buttons, top-rule workbench sections, 76px course rows, explicit recovery empty states, and fixed mobile navigation.
- Typography: Instrument Serif for academic emphasis, DM Sans for operational UI, JetBrains Mono for codes and data.
