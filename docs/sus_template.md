## SUS Scoring Formula

For each participant:

1. For odd-numbered questions (1, 3, 5, 7, 9), subtract 1 from the response.
2. For even-numbered questions (2, 4, 6, 8, 10), subtract the response from 5.
3. Add the adjusted scores for all 10 questions.
4. Multiply the total by 2.5.

Formula:

```text
SUS Score = ((Q1-1) + (5-Q2) + (Q3-1) + (5-Q4) + (Q5-1) + (5-Q6) + (Q7-1) + (5-Q8) + (Q9-1) + (5-Q10)) * 2.5
```

## Interpretation Guide

| SUS Score Range | Interpretation |
|---:|---|
| 85-100 | Excellent usability |
| 70-84 | Good usability |
| 50-69 | Acceptable but needs improvement |
| 0-49 | Poor usability |

## Reporting Note

Only report average SUS score, participant count, and interpretation after collecting real participant responses. If no participant testing was completed, state that the SUS instrument was prepared but no SUS score is reported.
